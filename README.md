# Python DA Assignment 1 – Data Analysis using NumPy and Pandas

## Overview
This assignment focuses on learning the fundamentals of data analysis using Python libraries, NumPy and Pandas. It covers numerical operations, array manipulation, Series operations, and DataFrame analysis.

## Technologies Used
- Python
- NumPy
- Pandas
- Jupyter Notebook

## Assignment Topics

### 1. NumPy Array Operations
- Creating 1D and 2D NumPy arrays
- Inspecting array shape, data type, and size
- Converting Celsius temperatures to Fahrenheit
- Finding maximum, minimum, and mean values
- Array indexing and slicing
- Extracting weekly and weekend temperatures

### 2. Pandas Series
- Creating a Series with custom index labels
- Accessing elements using `iloc` and `loc`
- Boolean indexing and filtering
- Modifying and removing Series elements
- Calculating CGPA from marks

### 3. Pandas DataFrame
- Creating a DataFrame from transaction data
- Exploring data using `head()`, `tail()`, `shape`, and `info()`
- Selecting specific columns
- Filtering rows using conditions
- Finding value counts and unique values
- Grouping data and calculating mean values
- Adding, modifying, and deleting columns and rows


## Learning Outcomes

- Understanding NumPy arrays and their properties.
- Performing basic numerical computations using NumPy.
- Working with Pandas Series and DataFrames.
- Applying indexing, slicing, and filtering techniques.
- Performing basic data exploration and manipulation.
